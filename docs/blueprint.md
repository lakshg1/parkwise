# **App Name**: ParkWise

## Core Features:

- Real-time Availability: Display available car and bike slots with dynamic pricing. Cache availability data.
- Smart Slot Allocation: Automatically allocates parking slots based on vehicle type and availability. Algorithm optimizes space, allowing car slots to accommodate bikes.
- Booking Management: Create, view, and cancel parking bookings.
- Pricing Rule Configuration: Admin interface to configure time-based pricing rules.
- Report Generation: Generate and export occupancy and revenue reports by lot and date. A tool will analyze collected parking data to make suggestions.
- User Authentication: JWT-based user authentication for user and admin roles.
- Notifications: Send notifications for booking confirmations and cancellations. (This MVP will just display on success).

## Style Guidelines:

- Primary color: Deep sky blue (#00BFFF) for a clean and modern feel.
- Background color: Light cyan (#E0FFFF), providing a light, airy background.
- Accent color: Medium slate blue (#7B68EE) for interactive elements and highlights.
- Body and headline font: 'Inter' sans-serif font for a modern, neutral, objective feel. Use 'Inter' for all text.
- Use minimalist icons to represent parking lots, car/bike slots, and booking actions.
- Responsive layout adapts to different screen sizes; displays real-time availability.
- Subtle animations when slots are booked or become available.
